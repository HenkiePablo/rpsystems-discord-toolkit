# Contributing

Thanks for considering a contribution to RPSystems Discord Toolkit.

## Before you start

- Search existing issues before opening a new one.
- Keep contributions focused on reusable Discord/FiveM tooling.
- Do not submit proprietary RPSystems code, customer data, credentials or deployment secrets.

## Development

Requirements:

- Node.js 20 or newer
- npm

Run the test suite with:

```bash
npm test
```

## Pull requests

A useful pull request should:

- explain the problem it solves
- keep the public API small and documented
- add or update tests where behavior changes
- avoid unnecessary dependencies
- avoid logging or exposing secrets

## Bug reports

Please include:

- Node.js version
- operating system
- toolkit version or commit
- minimal reproduction steps
- expected behavior
- actual behavior

## Feature proposals

Feature requests are welcome when they provide reusable value for Discord or FiveM bot maintainers rather than project-specific business logic.
